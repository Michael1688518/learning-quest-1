# Learning Quest v3.0

Modular browser learning app. Open `index.html` for the main version or `harry_index.html` for Harry's version.

Files:
- index.html
- harry_index.html
- styles.css
- app.js
- content.js

Current v3.0 foundation includes six learning centers, RAZ AA–F reading skills, Chinese/English/German/Math/Science starter question banks, answer explanations, wrong-answer animation, local progress persistence, and a parent learning log.

This package intentionally separates content from UI so larger curriculum banks can be added without rewriting the application shell.
